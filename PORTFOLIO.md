## Featured public project — Overtakr

**Overtakr** is a full-stack Formula 1 strategy intelligence application built to demonstrate product engineering beyond a typical CRUD portfolio app.

It combines:

- race-strategy simulation;
- visual strategy comparison;
- driver race narratives;
- lap-by-lap overtake and position-change analysis;
- reproducible scenario URLs;
- a typed Next.js/TypeScript frontend;
- a FastAPI/Python analytics backend;
- FastF1 race data with an offline-cache fallback;
- Docker and cloud deployment configuration.

### Why I built it

I wanted one public project that shows the complete path from a product idea to a usable engineering system: UI, state, API contracts, data processing, deployment concerns and failure handling.
