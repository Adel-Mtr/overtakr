Full-stack F1 strategy intelligence Public project

Race simulation, driver storytelling and overtake analytics in one application.

Overtakr is designed as a complete engineering case study rather than a tutorial-style portfolio app. It combines a typed Next.js/TypeScript UI with a FastAPI analytics service, FastF1 race data, simulation logic, visual comparison tools and deployment-ready infrastructure.

  • Driver digest and lap-by-lap movement analysis
  • FastF1 + Pandas data processing with local cache fallback
